# Meta Printer Automator - Menlo Park Offices

Created by Scott Bohr

*Note: All URLs related to Meta/Facebook have been deprecated and are no longer valid*

Overview
==============================================
The Meta Printer Automator is a Python-based tool designed to streamline the process of installing printer drivers for the Menlo Park offices. 
This program allows users to select their building and zone, download the appropriate printer driver, and follow step-by-step instructions to complete the installation.

Features
==============================================
 - Building and Zone Selection: Users can select their specific building and zone within the Menlo Park campus to find the correct printer.
 - Automated Driver Download: The program automatically downloads the necessary printer driver based on the user's selection.
 - Step-by-Step Installation Instructions: Provides clear instructions to guide users through the installation process, including handling macOS security prompts.

Usage
==============================================
 - Run the Program: Execute the script in a Python environment.
 - Select Building and Zone: Input the building number (20-23) and zone or floor as prompted.
 - Choose Printer: Select the desired printer from the list provided.
 - Download Driver: The program will automatically download the printer driver.
 - Follow Instructions: Follow the on-screen instructions to complete the installation.

System Requirements
==============================================
 - Operating System: macOS
 - Python: Version 3.x
 - Internet Connection: Required for downloading printer drivers

Installation
==============================================
 - Clone the Repository: Use git clone to download the project files.
 - Install Python: Ensure Python 3.x is installed on your system.
 - Run the Script: Execute the script using a Python interpreter.

Troubleshooting
==============================================
 - Security Prompts: If macOS blocks the application, follow the provided instructions to allow the app to run.
 - Network Connection: Ensure you are connected to the Meta network via Lighthouse or VPN to access printer servers.
